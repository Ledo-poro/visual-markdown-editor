# Visual Markdown Editor - Enhanced with 6 Color Themes

## ✨ What's New

### 🎨 6 Color Themes with Symbols
Your editor now features 6 beautiful themes, each with its own unique symbol:

1. **🌙 Violet** - Classic midnight mode with purple and gold accents
2. **⭐ Amber** - Warm vintage gold tones  
3. **🌊 Ocean** - Cool blues and cyan for focused work
4. **🌿 Forest** - Natural greens for peaceful editing
5. **🌅 Sunset** - Energetic oranges and reds
6. **⚡ Cyberpunk** - Bold neon cyan and magenta

### 🔄 Theme Switching
- Click the **🌙 Theme** button to cycle through all 6 themes
- Your selected theme is automatically saved in browser storage
- The theme name displays next to the button

### 📚 Symbol Guide
Two ways to access the guide:

1. **In-App Guide** - Click the **? Guide** button in the editor header
   - Shows all markdown symbols in a table
   - Displays all 6 themes with color previews
   - Includes formatting tips and combinations

2. **Dedicated Guide Page** - Open `guide.html`
   - Comprehensive documentation of all features
   - Detailed theme descriptions and color codes
   - Quick reference section
   - Keyboard shortcuts guide

### 📝 Markdown Symbols Supported

| Symbol | Usage | Example |
|--------|-------|---------|
| `#` | Heading 1 | `# My Title` |
| `##` | Heading 2 | `## Subtitle` |
| `-` | Bullet point | `- Item` |
| `**text**` | Bold | `**Bold**` |
| `*text*` | Italic | `*Italic*` |
| `` `code` `` | Code snippet | `` `const x` `` |
| `>` | Blockquote | `> Quote` |
