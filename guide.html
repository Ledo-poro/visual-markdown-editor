📝 Markdown Symbols & Usage

Learn how to use markdown symbols to format your text beautifully:

Symbol Name Usage Example
# Heading 1 Large title/header # My Main Title
## Heading 2 Subheading ## My Subtitle
- Bullet Point Create lists - First item
**text** Bold Emphasize important text This is **bold** text
*text* Italic Slight emphasis This is *italic* text
`code` Code Highlight code snippets `const x = 5`
> Blockquote Quote or highlight text > This is a quote

✨ Advanced Combinations

Combination Result Use Case
**_text_** Bold Italic Maximum emphasis
# + **text** Bold Heading Important titles
> + **text** Bold Quote Highlight quotes
- + **text** Bold Bullet Emphasis in lists

💡 Helpful Tips

  • Theme Persistence: Your selected theme is saved automatically and will be remembered when you return
  • Cycle Themes: Click the theme button to cycle through all 6 themes in sequence
  • Live Preview: See your markdown changes instantly as you type
  • Combine Symbols: Mix **bold**, *italic*, and `code` for rich formatting
  • Block Elements: Use blockquotes (>) for important information or quotes
  • Organize Content: Use multiple heading levels (# and ##) to structure your document
  • Code Highlighting: Use backticks (`) to highlight inline code snippets
